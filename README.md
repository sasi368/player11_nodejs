🏆 Player11 Backend (Node.js + Express + MongoDB)
This is the backend for Player11, a fantasy sports application. It provides APIs for user authentication, match listings, contests, team creation, and contest participation.

✔️ Upcoming Match List – Fetch and display matches
✔️ Contest Management – Create & join fantasy contests
✔️ Team Management – Build and save fantasy teams

🚀 Future Development
✅ Wallet System – Deposits, withdrawals & transactions
✅ Live Score Integration – Real-time match updates
✅ Leaderboards & Rewards – User rankings & prize pools
✅ Admin Panel – Manage users, contests & finances
